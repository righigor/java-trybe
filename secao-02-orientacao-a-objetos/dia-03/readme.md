# Classes Abstratas e Interfaces

Hoje vou explorar mais alguns conceitos fundamentais da programação orientada a objetos. Esses conceitos são cruciais para aprimorar minhas habilidades de programação e me equipar para resolver desafios práticos no mundo de desenvolvimento de software.

Vou estudar os seguintes conceitos:

- Métodos e Classes Abstratas;
- Interfaces;
- Herança entre Classes Abstratas ou Interfaces;
- Modificador final;
- Conversão (cast) de objetos.
